# 2027 義大利家庭十日互動旅遊網站

## 給接手 Codex 的指示

請依本文件建立實際專案檔案、安裝依賴、執行測試並啟動互動預覽。
不要只回覆開發建議或再次貼出原始碼。

先讀取目前專案的 AGENTS.md，檢查既有檔案再施工，避免覆蓋使用者內容。

這是舊對話產生的文字版程式碼整理。
尚未建立專案、安裝依賴、編譯、進行瀏覽器測試或部署。
請檢查並修正程式碼，不可假設測試已通過。

先完成本機互動版。
Supabase 未設定時必須正常使用 localStorage。
不要因缺少 Supabase、Vercel 設定或旅行社原稿而停止開發。

## 已確認需求

- 旅行日期：2027/1/2～1/11，共 Day 1～Day 10。
- 2027/1/5 為威尼斯自由活動。
- 使用者為繁體中文使用者、第一次到義大利旅遊的家庭。
- 考量冬季、長輩、交通、費用、休息與備案。
- 手機優先，文字及按鈕容易閱讀。
- React、TypeScript、Leaflet、OpenStreetMap。
- 本機保存優先，後續使用 Supabase、Vercel。

## 資料限制

目前沒有旅行社完整原行程圖片、PDF 或網址。

除日期與 1/5 威尼斯自由活動外，
其他日期的城市、景點、飯店、航班、餐食與集合資訊，
一律待確認，不得自行編造。

保留每日「旅行社原稿」與「原稿來源」。
自行規劃與旅行社安排必須清楚區分。

1/5 初始內容為建議，並非已確認或預訂：
- 10:30 聖馬可廣場與教堂周邊，90 分鐘。
- 12:00 午餐與休息，75 分鐘，餐廳未選定。
- 13:30 里亞托橋周邊，45 分鐘，依體力決定。
- 14:30 咖啡休息與返程準備，60 分鐘。
- 各站之間交通時間另計。
- 住宿及集合資訊未確認，返程時間須另核對。
- 雨天縮短活動；強風、濃霧或高水位時依交通公告調整。

2027 年的票價、開放時間與班次須再次查官方來源。
不要將目前資訊視為未來保證。

## 功能

1. Day 1～Day 10 日期切換。
2. 中義景點名稱、照片及授權來源、歷史故事與來源。
3. 建議停留、自訂停留、抵達與自動計算離開時間。
4. 跨午夜顯示「次日」。
5. 新增、修改、刪除、上下排序、備註。
6. Leaflet 地圖、Google Maps 導航。
7. localStorage 保存、JSON 匯出／匯入與驗證。
8. 每日旅行社原稿獨立保存。
9. Supabase 電子郵件登入、帳號隔離及手動同步。
10. 雲端版本衝突時不覆蓋較新的資料。
11. 未設定雲端時顯示本機模式。
12. 義大利當地時間 Europe/Rome，不隨裝置時區換算。

目前雲端設計是同一登入帳號跨裝置同步，
不是多帳號家庭共同編輯，也不是即時協作。

```ts
import { z } from "zod";

const text = z.string().max(20000);

const link = z.union([
  z.literal(""),
  z.string().max(2000).url().refine(
    value => value.startsWith("https://"),
    "網址必須使用 HTTPS"
  )
]);

export const StopSchema = z.object({
  id: z.string().uuid(),
  zh: z.string().min(1).max(200),
  it: z.string().max(200),
  kind: z.enum(["agency", "self"]),
  status: z.enum(["pending", "confirmed"]),
  story: text,
  source: link,
  image: link,
  imageSource: link,
  credit: z.string().max(500),
  license: link,
  suggested: z.number().int().min(0).max(1440),
  minutes: z.number().int().min(0).max(1440),
  arrival: z.union([
    z.literal(""),
    z.string().regex(/^([01]\d|2[0-3]):[0-5]\d$/)
  ]),
  note: text,
  lat: z.number().min(-90).max(90).nullable(),
  lng: z.number().min(-180).max(180).nullable()
}).refine(
  stop => (stop.lat === null) === (stop.lng === null),
  "經緯度須一起填寫或一起留白"
);

export const DaySchema = z.object({
  date: z.string(),
  agencyOriginal: text,
  agencySource: text,
  note: text,
  stops: z.array(StopSchema).max(100)
});

export const TripSchema = z.object({
  version: z.literal(1),
  title: z.string().min(1).max(200),
  days: z.array(DaySchema).length(10)
}).superRefine((trip, ctx) => {
  const ids = new Set<string>();

  trip.days.forEach((day, i) => {
    if (day.date !== dateOf(i)) {
      ctx.addIssue({
        code: z.ZodIssueCode.custom,
        message: "日期須依序為 2027/1/2～1/11"
      });
    }

    day.stops.forEach(stop => {
      if (ids.has(stop.id)) {
        ctx.addIssue({
          code: z.ZodIssueCode.custom,
          message: "景點 ID 不可重複"
        });
      }
      ids.add(stop.id);
    });
  });
});

export type Stop = z.infer<typeof StopSchema>;
export type Day = z.infer<typeof DaySchema>;
export type Trip = z.infer<typeof TripSchema>;

export function dateOf(index: number) {
  return `2027-01-${String(index + 2).padStart(2, "0")}`;
}

export function departure(arrival: string, minutes: number) {
  if (!arrival) return "待設定";

  const [h, m] = arrival.split(":").map(Number);
  const total = h * 60 + m + minutes;
  const next = Math.floor(total / 1440);

  return `${next ? "次日 " : ""}${String(
    Math.floor(total / 60) % 24
  ).padStart(2, "0")}:${String(total % 60).padStart(2, "0")}`;
}
```

```tsx
function download(
  name: string,
  value: string,
  type = "application/json"
) {
  const url = URL.createObjectURL(new Blob([value], { type }));
  const a = document.createElement("a");
  a.href = url;
  a.download = name;
  a.click();
  setTimeout(() => URL.revokeObjectURL(url), 1000);
}

function MapView({ stops }: { stops: Stop[] }) {
  const node = useRef<HTMLDivElement>(null);

  useEffect(() => {
    if (!node.current) return;

    const map = L.map(node.current).setView([42.6, 12.5], 5);

    L.tileLayer(
      "https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png",
      {
        attribution:
          '&copy; <a href="https://www.openstreetmap.org/copyright">OpenStreetMap</a>',
        maxZoom: 19
      }
    ).addTo(map);

    const points: L.LatLngExpression[] = [];

    stops.forEach((stop, index) => {
      if (stop.lat === null || stop.lng === null) return;

      const point: L.LatLngExpression = [stop.lat, stop.lng];
      points.push(point);

      const label = document.createElement("span");
      label.textContent = `${index + 1}. ${stop.zh}`;

      L.circleMarker(point, {
        radius: 10,
        color: "#124c46",
        fillColor: "#e8b86d",
        fillOpacity: 1
      }).addTo(map).bindPopup(label);
    });

    if (points.length) {
      map.fitBounds(L.latLngBounds(points), {
        padding: [35, 35],
        maxZoom: 15
      });
    }

    const observer = new ResizeObserver(() => map.invalidateSize());
    observer.observe(node.current);

    return () => {
      observer.disconnect();
      map.remove();
    };
  }, [stops]);

  return (
    <div
      ref={node}
      className="map"
      aria-label="當日景點互動地圖"
    />
  );
}

function Editor({
  stop,
  save,
  cancel
}: {
  stop: Stop;
  save: (value: Stop) => void;
  cancel: () => void;
}) {
  const [draft, setDraft] = useState(stop);
  const [error, setError] = useState("");

  function field(key: keyof Stop, value: unknown) {
    setDraft(current => ({ ...current, [key]: value }));
  }

  return (
    <section className="editor" aria-label="景點編輯器">
      <h3>編輯景點</h3>

      <form onSubmit={event => {
        event.preventDefault();
        const result = StopSchema.safeParse(draft);

        if (!result.success) {
          setError(result.error.issues.map(i => i.message).join("；"));
          return;
        }

        save(result.data);
      }}>
        {([
          ["zh", "中文名稱"],
          ["it", "義大利文名稱"]
        ] as const).map(([key, label]) => (
          <label key={key}>
            {label}
            <input
              value={draft[key]}
              required={key === "zh"}
              maxLength={200}
              onChange={e => field(key, e.target.value)}
            />
          </label>
        ))}

        <div className="grid">
          <label>
            行程分類
            <select
              value={draft.kind}
              onChange={e => field("kind", e.target.value)}
            >
              <option value="self">自行規劃</option>
              <option value="agency">旅行社安排</option>
            </select>
          </label>

          <label>
            核對狀態
            <select
              value={draft.status}
              onChange={e => field("status", e.target.value)}
            >
              <option value="pending">待確認</option>
              <option value="confirmed">已自行核對</option>
            </select>
          </label>

          <label>
            建議停留／分鐘
            <input
              type="number"
              min="0"
              max="1440"
              value={draft.suggested}
              onChange={e => field("suggested", Number(e.target.value))}
            />
          </label>

          <label>
            自訂停留／分鐘
            <input
              type="number"
              min="0"
              max="1440"
              value={draft.minutes}
              onChange={e => field("minutes", Number(e.target.value))}
            />
          </label>

          <label>
            抵達／義大利當地時間
            <input
              type="time"
              value={draft.arrival}
              onChange={e => field("arrival", e.target.value)}
            />
          </label>

          <label>
            預計離開
            <output>{departure(draft.arrival, draft.minutes)}</output>
          </label>
        </div>

        {([
          ["story", "歷史故事"],
          ["note", "備註／交通／費用／備案"]
        ] as const).map(([key, label]) => (

            {label}

              value={draft[key]}

            />
          </label>
        ))}

        {([
          ["source", "資料來源 HTTPS 網址"],
          ["image", "照片 HTTPS 網址"],
          ["imageSource", "照片來源頁 HTTPS 網址"],

function Photo({ stop }: { stop: Stop }) {
  const [failed, setFailed] = useState(false);

  if (!stop.image) return null;

  return (
    <figure>
      {failed ? (
        <p>照片暫時無法載入，可開啟來源查看。</p>
      ) : (
        <img
          src={stop.image}
          alt={stop.zh}
          loading="lazy"
          onError={() => setFailed(true)}
        />
      )}

      <figcaption>
        {stop.credit || "照片作者待補"}
        {" · "}

        {stop.imageSource && (
          <a
            href={stop.imageSource}
            target="_blank"
            rel="noreferrer"
          >
            圖片來源
          </a>
        )}

        {" "}

        {stop.license && (
          <a
            href={stop.license}
            target="_blank"
            rel="noreferrer"
          >
            授權
          </a>
        )}
      </figcaption>
    </figure>
  );
}

function App() {
  const [trip, setTrip] = useState<Trip>(readLocal);
  const [selected, setSelected] = useState(3);
  const [editing, setEditing] = useState<Stop | null>(null);
  const [message, setMessage] = useState("");
  const [session, setSession] = useState<Session | null>(null);
  const [email, setEmail] = useState("");
  const [busy, setBusy] = useState(false);
  const [revision, setRevision] = useState<number | null>(null);

  const [storageBlocked, setStorageBlocked] = useState(() => {
    try {
      const raw = localStorage.getItem(LOCAL_KEY);
      return !!raw && !TripSchema.safeParse(JSON.parse(raw)).success;
    } catch {
      return true;
    }
  });

  const day = trip.days[selected];

  useEffect(() => {
    if (storageBlocked) return;

    try {
      localStorage.setItem(LOCAL_KEY, JSON.stringify(trip));
    } catch {
      setMessage("本機儲存失敗，請立即匯出 JSON 備份。");
    }
  }, [trip, storageBlocked]);

  useEffect(() => {
    if (!cloud) return;

    let active = true;

    cloud.auth.getSession().then(({ data, error }) => {
      if (!active) return;
      if (error) setMessage(error.message);
      setSession(data.session);
    });

    const { data } = cloud.auth.onAuthStateChange((_event, next) => {
      setSession(next);
      setRevision(null);
    });

    return () => {
      active = false;
      data.subscription.unsubscribe();
    };
  }, []);

  function updateDay(patch: Partial<Day>) {
    setTrip(current => ({
      ...current,
      days: current.days.map((value, index) =>
        index === selected ? { ...value, ...patch } : value
      )
    }));
  }

  function saveStop(stop: Stop) {
    const exists = day.stops.some(s => s.id === stop.id);

    updateDay({
      stops: exists
        ? day.stops.map(s => s.id === stop.id ? stop : s)
        : [...day.stops, stop]
    });

    setEditing(null);
  }

  function move(index: number, direction: number) {
    const next = [...day.stops];
    const target = index + direction;

    if (target < 0 || target >= next.length) return;

    [next[index], next[target]] = [next[target], next[index]];
    updateDay({ stops: next });
  }

  async function run(action: () => Promise<void>) {
    setBusy(true);

    try {
      await action();
    } catch (error) {
      setMessage(
        error instanceof Error ? error.message : "操作失敗"
      );
    } finally {
      setBusy(false);
    }
  }

  async function upload() {
    if (!cloud || !session) return;

    const payload = TripSchema.parse(trip);
    const owner = session.user.id;

    if (revision === null) {
      const { data, error } = await cloud
        .from("family_trips")
        .insert({
          owner_id: owner,
          payload,
          revision: 1
        })
        .select("revision")
        .single();

      if (error) {
        if (error.code === "23505") {
          throw new Error(
            "雲端已有行程。請先匯出本機備份，再下載雲端版本。"
          );
        }
        throw new Error(error.message);
      }

      setRevision(data.revision);
    } else {
      const { data, error } = await cloud
        .from("family_trips")
        .update({
          payload,
          revision: revision + 1,
          updated_at: new Date().toISOString()
        })
        .eq("owner_id", owner)
        .eq("revision", revision)
        .select("revision");

      if (error) throw new Error(error.message);

      if (!data?.length) {
        throw new Error(
          "其他裝置已更新。請先匯出本機備份，再下載雲端版本。"
        );
      }

      setRevision(data[0].revision);
    }

    setMessage("已將這次快照上傳。後續修改仍需按「上傳雲端」。");
  }

  async function pull() {
    if (!cloud || !session) return;

    const { data, error } = await cloud
      .from("family_trips")
      .select("payload,revision")
      .eq("owner_id", session.user.id)
      .maybeSingle();

    if (error) throw new Error(error.message);

    if (!data) {
      throw new Error("這個帳號尚無雲端行程，可先上傳。");
    }

    const parsed = TripSchema.parse(data.payload);

    if (!confirm(
      "下載會取代目前本機行程。請確認已匯出需要保留的內容。"
    )) return;

    setTrip(parsed);
    setRevision(data.revision);
    setEditing(null);
    setMessage("已下載雲端版本。");
  }

  async function importFile(file?: File) {
    if (!file) return;

    if (file.size > 2_000_000) {
      throw new Error("JSON 檔案不得超過 2 MB。");
    }

    const parsed = TripSchema.parse(JSON.parse(await file.text()));

    if (!confirm("匯入會取代目前行程，確定繼續？")) return;

    setTrip(parsed);
    setRevision(null);
    setEditing(null);
    setMessage("已匯入；雲端尚未變更。");
  }

  return (
    <>
      <header>
        <span className="eyebrow">ITALIA · 02—11 JAN 2027</span>
        <h1>一起去義大利</h1>
        <p>家庭十日旅程 · 慢慢走，留時間看風景</p>
        <small>
          所有行程時間均為義大利當地時間 Europe/Rome
        </small>
      </header>

      <main>
        <aside className="notice">
          <strong>旅行社原行程尚待核對</strong>
          <p>
            十日日期已建立。1/5 為自行規劃建議，其他日期尚無景點資料。
            票價、開放時間、住宿及集合資訊不得視為已確認。
          </p>
        </aside>

        {storageBlocked && (
          <aside className="notice">
            <strong>
              原本機資料無法解析，自動保存已暫停。
            </strong>

            <div className="actions">
              <button onClick={() => {
                try {
                  download(
                    "local-recovery.txt",
                    localStorage.getItem(LOCAL_KEY) ?? "",
                    "text/plain"
                  );
                } catch {
                  setMessage("無法讀取本機資料。");
                }
              }}>
                下載原始資料
              </button>

              <button
                className="secondary"
                onClick={() => {
                  if (confirm(
                    "將以目前畫面內容取代原本機資料，確定？"
                  )) {
                    setStorageBlocked(false);
                  }
                }}
              >
                啟用目前行程保存
              </button>
            </div>
          </aside>
        )}

        <nav className="days" aria-label="選擇旅遊日期">
          {trip.days.map((value, index) => (
            <button
              key={value.date}
              aria-current={selected === index ? "date" : undefined}
              onClick={() => {
                setSelected(index);
                setEditing(null);
              }}
            >
              Day {index + 1}
              <small>1/{index + 2}</small>
            </button>
          ))}
        </nav>

        <section>
          <div className="section-title">
            <div>
              <span className="eyebrow">DAY {selected + 1}</span>
              <h2>
                {day.date}
                {selected === 3 ? " · 威尼斯自由日" : " · 待核對"}
              </h2>
            </div>

            <button onClick={() => setEditing(blankStop())}>
              ＋ 景點
            </button>
          </div>

          <details>
            <summary>旅行社原稿與每日備註</summary>

            <label>

              <textarea
                value={day.agencyOriginal}
                placeholder="尚未取得；請貼上此日旅行社行程原文"
                onChange={e => updateDay({
                  agencyOriginal: e.target.value
                })}
              />
            </label>

            <label>
              原稿來源／檔名、頁碼或網址

                >

                </button>

                    );
                  })}
                >

                </button>
              </div>

              <small>
                不同帳號的雲端資料隔離。
                本機行程仍留在此瀏覽器，共用裝置請注意保存內容。
              </small>
            </>
          )}

          <p role="status" aria-live="polite">
            {busy ? "處理中…" : message}
          </p>
        </section>
      </main>

      <footer>
        Buon viaggio · 把時間留給家人，也留給沿途的風景。
      </footer>
    </>
  );
}
```

```ts
  });

  it("計算停留與跨午夜時間", () => {
    expect(departure("10:30", 90)).toBe("12:00");
    expect(departure("23:30", 90)).toBe("次日 01:00");
    expect(departure("", 90)).toBe("待設定");
  });

  it("拒絕錯誤日期、負數分鐘及不安全連結", () => {
    const trip = initialTrip();
    trip.days[0].date = "2027-02-02";

    expect(TripSchema.safeParse(trip).success).toBe(false);

    const second = initialTrip();
    second.days[3].stops[0].minutes = -10;

    expect(TripSchema.safeParse(second).success).toBe(false);

    const third = initialTrip();
    third.days[3].stops[0].source = "javascript:alert(1)";

    expect(TripSchema.safeParse(third).success).toBe(false);
  });

  it("拒絕只填一半的座標與重複 ID", () => {
    const trip = initialTrip();
    trip.days[3].stops[0].lat = null;

    expect(TripSchema.safeParse(trip).success).toBe(false);

    const second = initialTrip();
    second.days[3].stops[1].id = second.days[3].stops[0].id;

    expect(TripSchema.safeParse(second).success).toBe(false);
  });
});
```

## supabase.sql

本機互動版不必執行此檔。
正式接雲端時，在新的 Supabase 專案 SQL Editor 執行一次。

```sql
create table if not exists public.family_trips (
  owner_id uuid primary key
    references auth.users(id) on delete cascade,
  payload jsonb not null,
  revision integer not null default 1 check (revision > 0),
  updated_at timestamptz not null default now(),
  constraint valid_payload_size
    check (octet_length(payload::text) <= 2000000),
  constraint valid_payload_version
    check ((payload->>'version') = '1')
);

alter table public.family_trips enable row level security;

revoke all on public.family_trips from anon;

grant select, insert, update, delete
  on public.family_trips to authenticated;

create policy "read own trip"
  on public.family_trips
  for select
  to authenticated
  using ((select auth.uid()) = owner_id);

create policy "create own trip"
  on public.family_trips
  for insert
  to authenticated
  with check ((select auth.uid()) = owner_id);

create policy "update own trip"
  on public.family_trips
  for update
  to authenticated
  using ((select auth.uid()) = owner_id)
  with check ((select auth.uid()) = owner_id);

create policy "delete own trip"
  on public.family_trips
  for delete
  to authenticated
  using ((select auth.uid()) = owner_id);
```

## 接手開發時應優先檢查

這些是尚未驗證的實作注意事項：

1. 實際執行 TypeScript、Vitest 與 Vite 建置。
2. 確認目前 Node 版本支援安裝的套件。
3. 驗證 localStorage 不可用或資料損壞時不會靜默覆蓋。
4. 驗證 JSON 匯入失敗與使用者取消時原資料保持不變。
5. 補上會造成實際資料錯誤的必要輸入長度限制。
6. 行程草稿切換日期或離開編輯時，考慮提示未儲存內容。
7. 地圖及照片需要網路；本機保存不代表地圖可離線使用。
8. 地圖目前只顯示位置，沒有計算步行路線或交通時間。
9. 大運河、橋階與無障礙通行不能僅依 Google Maps 推斷。
10. 重新檢查照片來源、授權標示與載入行為。
11. 雲端上傳／下載期間避免本機編輯被下載結果覆蓋。
12. 檢查 Supabase TOKEN_REFRESHED 等驗證事件，
    不要無必要重設已知 revision。
13. 雲端應實測兩個帳號互不可讀取，以及兩裝置版本衝突。
14. RLS 與同步未實測前，不可宣稱雲端驗收完成。
15. 「已自行核對」只是使用者標記，不代表旅行社或官方認證。
16. 旅行社原稿目前是可編輯欄位，並非不可變更的稽核記錄。
17. 在約 390px 手機寬度操作，檢查欄位、按鈕及地圖無橫向溢出。
